## Step 1 — Spawn 3 parallel subagents (single message, 3 Agent calls, `general-purpose`)
Each prompt is self-contained (fresh agents, no shared context) and includes: the exact function signature and marker text to find, the exact SQL/logic to implement (below), the two files it's allowed to touch, and an explicit instruction not to edit anything outside its marked sections.

- **Subagent 1 — Transaction history**
  - `database/queries.py`: implement `get_recent_transactions(user_id, limit=10)` →
    `SELECT date, description, category, amount FROM expenses WHERE user_id = ? ORDER BY date DESC, created_at DESC LIMIT ?`; reformat each `date` from `YYYY-MM-DD` to `%b %d, %Y`; `description` → `"—"` if `NULL`; return list of dicts `{date, description, category, amount}` (empty list if none).
  - `app.py`: replace its TODO line with `transactions = get_recent_transactions(user_id)`

- **Subagent 2 — Summary stats**
  - `database/queries.py`: implement `get_summary_stats(user_id)` → `total_spent` via `COALESCE(SUM(amount),0)`, `transaction_count` via `COUNT(*)`, `top_category` via `SELECT category FROM expenses WHERE user_id=? GROUP BY category ORDER BY SUM(amount) DESC LIMIT 1` (or `"—"` if no rows). Return `{"total_spent": 0, "transaction_count": 0, "top_category": "—"}` when the user has no expenses.
  - `app.py`: replace its TODO line with `stats = get_summary_stats(user_id)`

- **Subagent 3 — Category breakdown**
  - `database/queries.py`: implement `get_category_breakdown(user_id)` → `SELECT category, SUM(amount) AS total FROM expenses WHERE user_id=? GROUP BY category ORDER BY total DESC`; compute `pct` as `round(total/grand_total*100)` per row, then adjust the **first row's** `pct` (largest, since sorted desc) by the leftover remainder so all `pct` values sum to exactly 100; return `[]` if no expenses. Each item is `{"name", "amount", "pct"}`.
  - `app.py`: replace its TODO line with the two-line remap:
    ```python
    raw_breakdown = get_category_breakdown(user_id)
    breakdown = [{"category": item["name"], "amount": item["amount"], "percent": item["pct"]} for item in raw_breakdown]
    ```
